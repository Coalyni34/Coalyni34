## 🔭 Current Project

### [ForestMSG](https://github.com/Coalyni34/Forest-Messenger)

A decentralized, anonymous, censorship-resistant P2P messenger.

- No servers
- No phone numbers
- End-to-end encryption (AES-256-GCM + Ed25519)
- Anonymous transport (I2P + Tor)
- P2P delivery via BitTorrent
- Open source (GPLv3)
